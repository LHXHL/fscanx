# BL-POC-007 fscanx-web 登录认证（默认账号）

## 目标

维护端从免登录硬注入改为最小认证门：默认账号 admin/admin123，写接口有身份门槛，会话过期自动登出。

## 当前状态

- 已完成：实现 + 全量验证（2026-11-16）。
- 已验证：单测 7/7（登录成功/失败/Content-Type 拒绝/登出失效/中间件拦截与放行/白名单）；headless 产物版 9/9（未登录重定向/错误凭据提示/登录进入/登录态数据加载/刷新保持/登出回登录页/登出后拦截/伪造 token 401 自动登出/零非预期 console 错误）；curl 补验（重启 token 失效、授权写通、无 token 写 401）。
- 发现问题：构建顺序坑（go build 先于 build.sh → 二进制 embed 旧前端，浏览器拿到旧 UI 假失败）——已入记忆，与 go:embed 产物版终验教训同源。
- 下一步：用户浏览器确认登录体验 → 验收闭合。

## 执行计划（已全部完成）

1. cmd/fscanx-web/auth.go：凭据常量 admin/admin123 + crypto/rand 内存会话 token + /api/user/login|logout + authMiddleware（/api/* 除 login；无效 → 200+{code:401} 信封，前端拦截器自动登出链零改动）。
2. main.go：路由注册 + mux 包中间件 + 启动横幅打印默认账号。
3. 前端：api/login 端点换真实 URL、main.ts 删免登录注入与未用 import。
4. 验证：单测 + headless 全链 + curl 重启/写接口抽查。

## 风险与边界

- token 随进程生命周期：重启即全量失效（预期行为，前端自动登出重登）。
- HTTP 明文传输凭据：本地回环工具语义（item 不做节声明）。
- 无防爆破限速：本地单用户，凭据改密=改常量重编译。
