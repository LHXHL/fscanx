# BL-FOC-001 focus 输出符号 ASCII 化

## 目标

重点标记从 `⚠️`（U+26A0+FE0F，emoji 呈现 2 列宽，部分终端按 1 列计算导致错位）改为 ASCII `*`，输出 `[*name]`，全终端零风险。

## 方案

- `mylib/finger/common/framework.go:133` `s.WriteString("⚠️")` → `s.WriteString("*")`
- `mylib/finger/doc/rule.md:154` "在输出时也会带有focus字样"（失实描述）→ `[*name]` 形态说明
- 新建 `mylib/finger/common/framework_test.go`（若包内无既有测试）：断言 IsFocus 的 String() 输出 `[*name]` 与版本号组合 `[*name:1.0]`，及非 focus 输出 `[name]`

## 风险

- `Framework.String()` 是全部引擎统一输出通道——爆炸半径即全部指纹输出行，属预期行为变更（用户拍板）。
- 全仓无代码/测试断言 ⚠️ 字面量（评审实测），无破坏面。

## 验证方式

1. 单测断言输出形态
2. grep U+26A0（裸 ⚠ 与 ⚠️）在 .go 与 mylib/finger/doc 零残留
3. `go build ./...` + finger 相关测试
4. CHANGELOG 记录

## 决策记录

- 符号四选一用户拍板 ASCII `*`（否决 `!`、▲、去 FE0F）。
