# BL-FOC-003 goby.json 中文形态化

## 目标

goby.json 全部 `\uXXXX` 转义（11971 处）解码为 UTF-8 原文，结构/缩进/键序不变，引擎行为不变。

## 方案

- 转换工具：`plans/scripts/convert_goby_unicode.py`（可复用）——raw_decode 逐 token 手术：非字符串区域原样保留，字符串 token 解码后 `ensure_ascii=False` 重编码；孤立代理保留原 token；验证 [1]-[4] 全过才落盘。
- 重打包：`go run ./mylib/finger/cmd/pack` + `go build .`

## 验证结果（全过）

1. 代理对+中文人工样例单测 PASS（`{"a":"😀","b":"中文"}`）
2. json.load 前后深度相等 PASS
3. 非字符串 token 逐字节不变 PASS
4. 纯 LF / 无 BOM / 无尾换行 PASS
5. \u 转义 11971 → 0；字节 2089079 → 2053147
6. 引擎取证（embed 已为中文化库）：NewGobyEngine Len==7075，中文特征抽样（"物联网供应链与金融风险管理服务"）匹配命中
7. pack：goby.json.gz 2053147 → 310928 bytes；`go build .` 通过

## 决策与教训记录

- 本机 bash heredoc 会折叠 `\\`→`\`，反斜杠敏感脚本必须走文件（探测结论曾被 heredoc 污染）。
- CPython json 代理对行为（文件级探测裁定，reviewer 争议已闭环）：**转义文本形式**的合法代理对会被组合为单一字符（与 RFC 8259 一致）；**裸代理字符输入**（shell 引号污染场景）不组合。fix_surrogates 的真实职责：孤立代理转义（解析为孤立代理字符、utf-8 编码会崩）时保留原 token 不动。
- reviewer 批量审查 APPROVE（16 验收项逐条亲证 + 变异测试证明单测防回归）；其"CPython 不组合代理对"的反驳经 t1/t2/t3 三组对照探测认定为输入类别混淆（t3 裸字符类）。
