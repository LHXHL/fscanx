# BL-POC-003 指纹定向触发管道

## 目标

空 `-pocname` 从"全量过渡"切换为终态"智能指纹定向"：指纹产品名查 binds 定向执行；无命中不打且不提示；`all`/显式名语义不变；`-m webpoc` 模式也先取指纹；PocDatas 退役为内置种子；死代码清理。

## 调查结论（实现依据）

- 指纹产出：`DoWebScan` 内 `Engine.DetectContent(body)`（webScanTask.go:652）返回 `common.Frameworks map[string]*Framework`——**map key 即原始产品名**（无 focus 渲染），遍历即得。
- `scanPresents.lineProducts` 是渲染串（`[*thinkphp]`），不适合做匹配源；原始名从 frames map 取。
- PocDatas 实为 **14 条**（rules.go:297-314，立项草稿"300+"是误读），alias 形态与引擎产品名一致（thinkphp/seeyon/weaver...）。
- binds 匹配语义：binds.product 与指纹名 Contains（双侧 ToLower）——`[*thinkphp]` 含 `thinkphp` 即命中。

## 方案

1. **指纹进 HostInfo**：`common/config.go` HostInfo 加 `Frames []string`（原始产品名），删死字段 `PocName`。`DoWebScan` 652 行处遍历 frames append 进 `targetInfo.Frames`（多次调用累积，查询幂等不去重）。favicon 指纹命中在链尾合并（faviconScan），实现时在该处同步 append（风险点，见下）。
2. **webpoc 轻量指纹**：webScanTask.go webpoc 分支 ensureURL 后调新函数 `detectProductsSilent(targetInfo)`（静默 GET 首页 + DetectContent，不拼 Product 行不输出——保持"仅 PoC"模式无 web 输出的语义）。
3. **三态分发**（PocScan()）：`all`→归一化全量；显式名→过滤；空→`boundPocNames(info.Frames)` 查 PocBinds（命中产品条目 + always 条目的 pocs 并集），非空逐名 Execute，空则直接 return（不打不提示）。
4. **内置种子 + 外置合并**（binds.go）：`PocScan/binds-seed.yaml` go:embed 作为默认层（14 条 PocDatas 转换：product=alias，pocs=内置库中 name 含 alias 的全部——构建期生成快照，提交仓库）；`loadBindsFile` 改两层：seed 打底 + 外置 binds.yaml 同 product 整条覆盖/异名追加。PocBinds 恒非空 → "清零"风险消除。
5. **清理**：HostInfo.PocName 字段、scanner.go:401 透传行、check.go CheckInfoPoc、rules.go PocDatas、client.go LoadMultiPoc/SelectPoc。

## 风险

- **favicon 指纹必须进 Frames**：favicon-only 产品（无文本特征）定向依赖它——接线点在 faviconScan 链尾合并处，实现时读代码确认，漏接则该类目标智能定向退化为不打。
- 种子快照与内置库演进漂移：种子只反映生成时刻的内置库，新增内置 poc 未入种子 → 智能定向少打（all 仍全）。文档记维护口径（重跑生成脚本）。
- webpoc 分支新增一次首页 GET：对每目标多 1 请求（预算可接受，与 web 模式对齐）。

## 验证（vulhub thinkphp 靶场复用 + 干净 python server）

- C1 智能定向：`-u 靶场 -m webpoc`（空 pocname）→ 容器日志只有 thinkphp 系请求 + RCE 命中行（非全量 386）
- C2 无命中不打：python http.server 目标 + 空 pocname → 零请求零提示
- C3 always：外置 binds.yaml 加 always 条目 → C2 目标也收到该 poc
- C4 回归：`all` 全量、显式名过滤、`-m all -poc` 场景不受影响
- C5 清理：全仓 grep 六符号零残留；build+vet+test 全过（binds 单测扩充覆盖合并/查询/always）
