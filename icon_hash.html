Icon Hash Calculator (MD5 / MMH3)

⚠️ 重要提示：
请粘贴本地 ICO 文件（从文件管理器复制文件后粘贴），不要从浏览器中右键复制图片。

原因：浏览器打开 favicon.ico 后会将其解码为位图（PNG/BMP），右键复制图片时复制的是解码后的像素数据，而非原始 ICO 文件字节。这导致计算出的哈希与原始 favicon 不一致，无法用于指纹匹配。

算法说明（2026-11-15 修正，与 fscanx 引擎 chainreactors/utils/encode 逐字节一致）：
  • MD5 = 图标原始字节的标准 MD5（小写 hex）
  • MMH3 = FOFA icon_hash 语义：图标先标准 base64 编码（每 76 字符插换行、末尾补换行，等价 Python base64.encodebytes），再对 base64 字符串算 MurmurHash3 x86_32（种子 0，有符号 32 位）——不是对原始字节直接算
正确操作方式：
  1. 在文件管理器中右键复制 favicon.ico 文件 → 回到此处 Ctrl+V 粘贴
  2. 或将 favicon.ico 文件拖拽到此处
  3. 或直接粘贴 favicon 的 URL 链接（受浏览器跨域限制，站点未开 CORS 会失败；失败请改用文件方式）
点击此处或 Ctrl+V 粘贴文件 / 链接
支持：本地 ICO 文件（推荐）、URL 链接。不支持从浏览器复制的图片。MMH3 为 FOFA icon_hash 语义（base64 后 mmh3）。
