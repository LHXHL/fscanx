# 当前实现总览

本文件是“代码里现在有什么”的地图：只列入口、职责与能力，不复制模块设计（见 [设计总览](设计总览.md) 与 [模块文档](modules/)）。

上次全面核对：2026-11-13

## 入口与主链路

| 文件 | 现有能力 |
|------|----------|
| `main.go` | `common.Flag` → `common.Parse`；按 `-msc`、`--std`、普通扫描三种模式分派；等待日志协程结束后关闭 `Results`。 |
| `common/flag.go` | 全部命令行参数定义、Banner、协程池/并发通道/超时/BloomFilter（存活 IP 去重）/拨号器初始化。 |
| `common/masscan_flag.go` | `-msc` 参数组合校验与 `-margs` 托管参数拒绝；`usesStdinLikePipeline` 派生判断。 |
| `common/Parse.go` | 用户名/密码/文件输入、代理与 hash 校验、`-m` 扫描类型到端口列表的映射、ICMP 限速器初始化。 |
| `common/ParseIP.go` | IP/网段/区间/域名输入展开、输入文件去重与改写、`-pd` 域名转 IP、`-dp` 域名端口绑定。 |
| `common/ParsePort.go` | 端口组、区间与逗号列表的展开（不含 `-pn` 排除）。 |

## 扫描与插件

| 位置 | 现有能力 |
|------|----------|
| `Plugins/scanner.go` | 普通扫描调度、大网段智能预扫描、`ScanFromReader` 标准输入管线（`--std`/`-msc` 共用）。 |
| `Plugins/portscan.go` | 端口扫描、存活判断、gonmap 协议识别、`--std` 单目标探测。 |
| `Plugins/*.go` | ftp、ssh、smb/smb2、rdp、mysql、mssql、oracle、postgres、redis、mongodb、memcached、fcgi、netbios、findnet、wmiexec、ms17010、CVE-2020-0796、icmp、qqwry 等协议插件与爆破。 |
| `Plugins/webScanTask.go` | Web 标题/ICP/证书/跳转/指纹识别，响应体限长读取。 |
| `Plugins/masscan.go` | `-msc` 的 masscan 查找、目标/端口转换、进程管理、stdout 流式解析、stderr 进度解析。 |
| `PocScan/` | Web POC 执行（`WebScan.go`）、YAML POC 加载与求值（`lib/`）、内置 POC 库（`pocs/`）。 |

## 公共能力与依赖

| 位置 | 现有能力 |
|------|----------|
| `common/log.go` | `Results` 通道消费、彩色终端输出、按需写入输出文件。 |
| `common/progress.go` | masscan 进度行擦除/重绘，TTY（真实终端）与 `-silent` 开关。 |
| `common/proxy.go` | HTTP/SOCKS5 代理拨号与连接超时处理。 |
| `common/LimitRate.go` | ICMP 发包令牌桶参数。 |
| `mylib/` | gonmap、finger、grdp、ftp、ssh、socks、proxy、stdio 等内置库；`simplehttp` 当前无引用，属待清理死代码。 |
| `PocScan/pocs/`、`mylib/finger/` | 内置 YAML POC 与 Web 指纹数据。 |
| `assets/`、`README.assets/` | README 使用的静态图片资源。 |
