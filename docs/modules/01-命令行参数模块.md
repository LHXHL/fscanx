# 模块：命令行参数

## 模块定位

负责 fscanx 的命令行契约：定义全部参数、决定默认值、校验互斥与依赖，并把用户输入转换成后续扫描需要的全局状态（目标、端口、并发、超时、代理、输出）。不包含目标格式展开（ParseIP）、端口展开（ParsePort）和实际扫描逻辑。

## 现状基线

| 组件 | 位置 | 现状 |
|---|---|---|
| 参数定义 | common/flag.go `Flag` | 标准库 `flag`；打印 Banner 后注册全部参数，默认值集中在注册处与 common/config.go |
| 参数组合校验 | common/masscan_flag.go `ValidateMasscanMode` | 在 `common.Parse` 之前校验 `-msc` 的互斥/必填，错误写 stderr 并以退出码 2 结束 |
| 派生初始化 | common/flag.go | 按 `-std/-msc` 选择并发模型；创建 Web/插件/爆破并发通道、pond 协程池、Nmap 超时、BloomFilter（存活 IP 去重）、代理拨号器 |
| 输入解析 | common/Parse.go `Parse` | 用户/密码/字典文件、`-u/-uf` URL、`-portf` 端口文件、代理规范化、`-m` 扫描类型到端口列表的映射、`ParseInput` 末尾的 ICMP 令牌桶初始化 |
| 目标格式 | common/ParseIP.go | IP、CIDR（网段）、区间、域名、逗号列表；`-pd` 域名转 IP；`-dp` 纯域名按 `-p` 端口生成 http/https URL |
| 端口格式 | common/ParsePort.go `ParsePort` | 端口组（如 `web`/`db`/`main`）、区间（`1-65535`）与逗号列表 |
| 模式分派 | main.go | `-msc` → `ScanWithMasscan`；`--std` → `ScanFromStdin`；否则 `Plugins.Scan` |

## 关键设计决策

- **标准库 flag + 全局变量**：参数直接写入 `common` 包全局配置，插件随处可读；代价是测试需要重置全局状态。
- **校验前置**：`-msc` 的组合校验放在 `common.Parse` 之前，避免 `ParseInput` 在缺少目标时先以 0 退出，把参数错误变成“成功”。
- **stdin 类管线单独派生**：`usesStdinLikePipeline = -std || -msc` 只用于并发模型与 BloomFilter 初始化；`-msc` 不设置 `ScanWithStdInput`，否则 main 会去读 `os.Stdin`。
- **`-dp` 只处理纯域名**：匹配域名正则的目标按 `-p` 端口生成 http/https URL，其余目标留在 Host 继续按 IP/CIDR 处理；`-msc` 会拒绝与 `-dp` 同用（masscan 的目标来源只有 `-h/-hf`）。`-u/-uf` 是独立 URL 输入，不走 `-dp`。
- **`ParseScantype` 只改端口**：扫描类型把端口列表替换成对应插件的端口（如 `-m web` 用 Web 端口集合）；调度层对 `-m icmp`/`-m portscan` 另有提前返回分支，不是单纯换端口。
- **输入文件的两种语义**：普通扫描的 `-hf` 走 `ReadInputFile`（会去重并原地改写用户文件，属历史行为）；`-msc` 的 `-hf` 走只读转换，不允许改写用户文件。

## 关键功能怎么做

### 参数解析与派生初始化

1. `Flag` 打印 Banner，注册全部参数并调用 `flag.Parse`。
2. `ValidateMasscanMode` 在 `-msc` 开启时校验：不能与 `-std/-dp/-u/-uf/-auto/-m icmp` 同用，必须有 `-h/-hf`，`-mr > 0`，`-margs` 不得包含托管参数；失败以退出码 2 结束。
3. 根据是否 stdin 类管线选择 Web 扫描并发（`-t` 或 `-tn`）；创建 `PluginTaskRateCtrlCh`、`BruteTaskRateCtrlCh`、`PoolScan`；计算 Nmap 总/单探针超时；Socks5 时强制 `AutoScanProtocols=tcp`；按需创建 BloomFilter。
4. 初始化代理拨号器；`ParseInput` 末尾按 `-prate` 计算 ICMP 发包速率并创建令牌桶（按速率发放发包配额）。

### 输入与扫描类型

- 目标来源：`-h`（逗号列表）、`-hf`（文件）、`-hn`（排除）、`-u/-uf`（URL）。
- `ParseUser/ParsePass` 覆盖默认用户字典与密码列表；`-usera/-pwda` 追加；`-portf` 用端口文件内容覆盖端口输入（`-p` 的值会被丢弃）。
- `ParseInput` 做空目标检查、`-pa` 端口追加、代理地址补全、hash 长度与 hex 校验、ICMP 限速参数计算。`-pn` 不在这一步生效：只在 `PortScanBatchTaskWithList`（ICMP/智能预扫描存活后或 `-hf` 批量目标）与 masscan 端口转换中相减；`--std` 管线与 NoPing 的按通道批量路径不应用该排除。
- `ParseScantype` 按 `-m` 把 `PortsInput` 替换为对应端口集合；未知类型打印可选值并退出。
- `-pd` 在文件输入处理时把域名解析出的 IPv4 按 `/24` 追加到目标列表；`-h` 的纯域名在 `parseSingleIPWithChan` 中本身就会做 DNS 解析（不依赖 `-pd`）。`-dp` 在 `common.Parse` 末尾调用 `ProcessDomainAsURL`，只处理域名目标。

### 错误处理

- 空目标（非 `--std`）打印 “Host is none” 与用法后退出。
- 代理格式非法、hash 长度错误、未知扫描类型等沿用历史行为，多数以 `os.Exit(0)` 结束；`-msc` 组合错误写 stderr 并以退出码 2 结束（需要与非零退出区分时以 `-msc` 路径为准）。
