# 指纹重点关注模块

## 模块定位

建设"重点关注"产品标记能力：高危/高价值产品的指纹在扫描输出中带 `*` 标记（`[*产品名]`），护网等场景下快速定位脆弱资产。代码域为 `mylib/finger`（focus 数据流：规则字段 → 引擎 Match → `Framework.IsFocus` → `String()` 输出），数据域为 goby.json 指纹库。

## 现状（立项基线，2026-11-14）

- fingers 引擎已有 focus：YAML/JSON 规则 `focus: true`（fingers.go `Finger.Focus`）→ 命中置 `frame.IsFocus`。
- goby 引擎（7075 条，最大单引擎）已支持内联 focus 字段（BL-FOC-002：goby.go `GobyFinger.Focus`，json `focus,omitempty`，命中置 `frame.IsFocus`，与 fingers 语义一致）。
- favicon 哈希命中路径已补 focus 传递（BL-FOC-005，2026-11-15）：fingers 库 focus 指纹的图标哈希命中同样置位——`FaviconsEngine.FocusNames` 并行表（按指纹名记）承载 focus，fingers 编译填充、引擎聚合拷贝、`HashMatch` 命中后置 `IsFocus`；覆盖 BL-FP-005 的 favicon 探测链路。
- 输出符号 `⚠️`（U+26A0 + FE0F，emoji 呈现）在 macOS 等终端错位。（FOC-001 后：已改为 ASCII `*`，输出 `[*产品名]`）
- goby.json 为 `\uXXXX` 转义形态（生成工具链默认 ASCII 序列化），中文特征不可读。（FOC-003 后：11971 处转义已全部解码为 UTF-8 原文，转换工具 plans/scripts/convert_goby_unicode.py）

## 关键决策

- **符号 ASCII 化（BL-FOC-001，用户拍板）**：`⚠️` → `*`。纯 ASCII 宽度恒定 1 列；否决 ▲（东亚两义宽度残余风险）与去 FE0F（macOS 字体层仍可能强制 emoji）。
- **goby 内联 focus 字段（BL-FOC-002，用户拍板）**：goby.json 条目直接加 `"focus": true`，与 fingers 概念一致、数据自包含；否决外置名单文件（多资源文件+合并逻辑+打包改动；goby.json 已本地维护，不存在官方整体替换场景）。
- **中文形态化走 token 级文本手术（BL-FOC-003）**：raw_decode 逐字符串解码重编码、非字符串 token 原样保留，禁整体重序列化；转换前后 json.load 深度相等作等价性证明。
- **favicon focus 按名存而非按哈希存（BL-FOC-005）**：`FocusNames map[string]bool` 以指纹名为键——同名多哈希只记一次且 md5/mmh3 通用；不改 `Md5Fingers/Mmh3Fingers` 的 map[string]string 结构（fingerprinthub/ehole 共用且无 focus 概念，避免连坐改动）。

## 维护工作流

### focus 打标（BL-FOC-004 落地）

1. 拟关键词清单 → `plans/scripts/scan_hw_focus.py` 生成命中明细（name 子串匹配 + 黑名单剔误伤），呈现确认
2. `plans/scripts/tag_hw_focus.py` 执行手术（逐条目在 logic 键行前插 `"focus": true`，验证前置：元素数/清单一致性/深度相等/LF 形态全过才落盘）
3. 项目根 `go run ./mylib/finger/cmd/pack` 重打包 → `go build .`

当前打标基线：7076 条中 focus 452（护网 9 类 451 + 若依 1），明细见 plans/2026-11-14-BL-FOC-004-护网打标.md。新增产品特征时按 goby 格式（name/focus/logic/rule，logic 为 label 布尔表达式）追加条目。

### ⚠ 行尾契约（重要教训）

goby.json 的格式契约是**纯 LF、无 BOM、无尾换行**（确定性打包依赖）。本仓库 `git core.autocrlf=true`（工作树常态 CRLF），**任何 `git stash`/`checkout` 往返都可能把该文件物化为 CRLF**——批量审查/基线取证若涉及 stash 往返，之后必须重验行尾（恢复即去 CR，与 gz 内容比对确认）。

### 打包

项目根 `go run ./mylib/finger/cmd/pack`（内置 json.Valid 校验 + 确定性 gzip，写 resources 根 embed 真源 goby.json.gz）→ `go build .`。详见 05 模块"指纹库维护工作流"。
