# 指纹重点关注模块 Backlog

## BL-FOC-001 focus 输出符号 ASCII 化

- 模块：指纹重点关注
- 优先级：P1
- 状态：已完成
- 价值：重点关注产品标记在任何终端（macOS Terminal、老式 conhost、重定向到文件）不再错位乱码。
- 关联模块文档：docs/modules/07-指纹重点关注模块.md
- 关联计划：plans/2026-11-14-BL-FOC-001-符号ASCII化.md
- 关联代码：mylib/finger/common/framework.go
- 验收状态：已验收

### 方案（立项时必填）

- **做什么**：`Framework.String()`（framework.go:133）的重点标记 `⚠️`（U+26A0 + 变体选择符 FE0F，强制 emoji 呈现）改为 ASCII `*`，输出形如 `[*Apache-Shiro]`。
- **为什么**：emoji 呈现按 2 列宽渲染，但部分终端按 1 列计算宽度，macOS Terminal 及部分终端实测错位/乱码（用户真机反馈）。
- **怎么做**：改 framework.go 一处常量；修正 mylib/finger/doc/rule.md:154 的输出形态描述（现写"输出时也会带有focus字样"不准确，实际输出是符号标记，改为 `[*name]` 形态说明；实测 doc 三文件无 ⚠️ 字样，无符号残留可清）。
- **为什么这么做**：用户四选一拍板 ASCII `*`。纯 ASCII 宽度恒定 1 列、全平台零风险；否决 ▲（U+25B2，宽度属东亚两义字符，个别终端仍错位）与"保留 ⚠ 去 FE0F"（macOS 字体层仍可能强制 emoji 渲染，风险未根除）。

### 范围

- framework.go `String()` 符号常量
- mylib/finger/doc/rule.md 输出形态描述修正（rule.md:154）
- CHANGELOG

### 不做

- `--filter focus` 过滤能力（上游工具能力，本仓库未实现，rule.md 系继承描述）
- JSON 字段 `is_focus`（数据形态不变）

## BL-FOC-003 goby.json 中文形态化（\u 转义解码）

- 模块：指纹重点关注
- 优先级：P1
- 状态：已完成
- 价值：goby.json 人可读——中文特征（feature 值）以原文呈现，人工审计与打标定位不再面对 `\uXXXX` 盲文。
- 关联模块文档：docs/modules/07-指纹重点关注模块.md
- 关联计划：plans/2026-11-14-BL-FOC-003-goby中文化.md（转换工具 plans/scripts/convert_goby_unicode.py）
- 关联代码：mylib/finger/resources/goby.json/goby.json
- 验收状态：已验收

### 方案（立项时必填）

- **做什么**：goby.json 中全部 `\uXXXX` 转义解码为 UTF-8 原文，文件结构、缩进（2 空格/层）、键序不变。
- **为什么**：生成工具链默认 ASCII 安全序列化（Go `json.MarshalIndent` / Python `ensure_ascii=True` 都把非 ASCII 转 `\uXXXX`）；中文 feature 是国产产品识别的主要特征，转义形态导致不可读，是打标与人工审计的实际障碍。
- **怎么做**：raw_decode 逐 JSON token 文本手术——非字符串 token（结构符/数字/布尔/空白）原样拷贝；字符串 token 解析后以 `ensure_ascii=False` 重编码（`"`、`\`、控制字符由序列化器正确转义，不会破坏结构）；禁整体重序列化。实施约束（Windows 环境回归点）：二进制模式或 `newline=''` 写出防 `\n` 被翻译为 `\r\n`（现文件纯 LF、零 CRLF）；不引入 BOM（现无）；不追加文件尾换行（现以 `}]` 结尾无尾换行）。
- **为什么这么做**：盲正则替换 `\uXXXX` 有真实陷阱——字符串值内的字面 `\u` 序列会被误伤，解码出 `"` / `\` 会破坏 JSON 结构；token 级手术配合"转换前后 json.load 深度相等"比对是唯一可验证等价的路径（方法沿用 05 模块 goby 文本手术经验：禁整体重序列化、raw_decode 定位消除转义歧义）。对引擎零影响：`中` 与 UTF-8 `中` 在 JSON 语义上等价，`json.Unmarshal` 解析结果相同。

### 范围

- goby.json/goby.json 全文 `\uXXXX` 解码
- 重打包：项目根 `go run ./mylib/finger/cmd/pack`（写 resources 根 embed 真源 goby.json.gz）
- CHANGELOG

### 不做

- fingers_http.json（本就是 UTF-8 中文原文）
- 缩进/键序/非 \u 转义风格的统一化（只解码 \u，其他一切字节不动）

### 验收条件

- [x] 转换前后 `json.load` 深度相等（对象级逐条比对）；转换脚本对人工构造的代理对样例单测通过（防御性条款：当前数据实测无 BMP 外字符）（实测：转换脚本断言 [1][2] PASS，样例输出 `{"a":"😀","b":"中文"}`）
- [x] 非字符串 token 文本逐字节不变（剔除字符串 token 后对剩余文本逐字节比对）；换行保持纯 LF、无 BOM、无尾换行（实测：断言 [3][4] PASS）
- [x] 引擎加载实测：GobyEngine 初始化成功、指纹数 7075 不变、含中文 feature 的指纹抽样匹配行为一致（实测：一次性取证测试——embed 已为中文化库，Len==7075，中文特征抽样"物联网供应链与金融风险管理服务"匹配命中）
